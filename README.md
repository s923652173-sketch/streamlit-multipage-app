# Streamlit 2 - Multipage App

A four-page Streamlit application following the official [Create a multipage app](https://docs.streamlit.io/get-started/tutorials/create-a-multipage-app) tutorial.

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run Hello.py
```

## Deploy

Upload all files and the `pages` directory to a public GitHub repository. Deploy through Streamlit Community Cloud with entrypoint `Hello.py`.

The Mapping Demo and DataFrame Demo download public sample data at runtime, so internet access is required.
